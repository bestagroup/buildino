# بررسی زنده پنل مدیر ساختمان — ۲۰۲۶/۱۱/۱۳

## دامنه و شواهد

بررسی با ورود واقعی و نقش مدیر ساختمان انجام شد. هیچ داده تولیدی ویرایش یا حذف نشد؛ محاسبه، صدور، پرداخت، ارسال دعوت یا پیامک انجام نشد. این گزارش تأیید کامل تراکنش‌ها یا صحت بانک اطلاعاتی نیست.

- داشبورد، مرکز عملیات، فهرست کاربران و دعوت‌ها، گزارش در یک نگاه و فهرست دسته‌های هزینه بارگذاری شدند.
- در یک نگاه، واحدها، نفرات و مانده صورتحساب‌ها را نمایش داد. صفر نمایش‌داده‌شده در فهرست مالی مسدودشده، شاهد نبود یا حذف صورتحساب نیست.
- بلوک‌ها، طبقات، واحدها، فرمول‌ها و چندین فهرست مالی پاسخ عدم وجود اشتراک قابل استفاده دریافت کردند.
- دوره‌های شارژ و امکانات/رزروها خطای مجوز عمومی نشان دادند؛ helper مشترک، همه پاسخ‌های 403 از جمله خطای اشتراک را به خطای مجوز تبدیل می‌کرد.
- تیکت‌های پشتیبانی پس از اتمام بارگذاری، پاسخ خالی بدون خطا نمایش دادند؛ اسناد و صورتجلسات نیز پاسخ خالی دادند.
- صفحه اطلاعیه‌ها خطای مجوز داشت. API و Policy این بخش سراسری است و فهرست آن به ساختمان محدود نشده؛ نمایش آن برای مجوز ساختمانی اشتباه بود.
- متن راهنمای ورود اکسل در محیط زنده با تغییرات commit 6bcb9d27 همخوان نبود؛ استقرار آخرین نسخه یا پاک‌سازی کش باید بررسی شود. نسخه commit اجراشده روی سرور مستقیماً تأیید نشده است.
- برخی صفحات فقط از نظر دسترسی و نمایش اولیه بررسی شدند. فرم‌های ذخیره‌سازی و تراکنش‌های مالی در محیط زنده به‌طور کامل آزموده نشده‌اند.

## اعتبارسنجی محدود به تغییر و وابستگی‌های آن

- SubscriptionLifecycleTest: چهار تست، ۱۹ assertion موفق.
- دو تست مرتبط با دسترسی اطلاعیه‌ها: هشت assertion موفق.
- core-flows: هفت تست موفق.
- invoice-credit-ui: یک سناریوی ترکیبی Vue در JSDOM موفق؛ شامل پنج فهرست و بازیابی پس از خطا. این اجرای DOM تأیید بصری یا واکنش‌گرایی مرورگر نیست.
- TypeScript typecheck، Vite production build و git diff --check موفق.
- کل تست‌های پروژه دوباره اجرا نشد.

## موارد باقی‌مانده برای محیط اصلی

1. وضعیت واقعی اشتراک ساختمان، تاریخ شروع/پایان و مهلت آن باید با دسترسی مجاز سرور بررسی و از مسیر رسمی مدیریت اشتراک اصلاح شود. مشاهده پیام عمومی، دلیل قطعی انقضا یا تعلیق را تعیین نمی‌کند. کنترل اشتراک دور زده نشد.
2. انتشار کد و build assets، به‌روزرسانی وابستگی‌ها مطابق deploy موجود و بازسازی کش Laravel لازم است. push به مخزن به معنی استقرار روی cPanel نیست.
3. پس از رفع مانع اشتراک، آزمون تراکنشی فرم‌ها و مسیر پیش‌نمایش/محاسبه/صدور روی داده آزمایشی لازم است؛ اجرای آن‌ها روی داده‌های واقعی انجام نشد.
4. اطلاعیه مخصوص ساختمان نیازمند طراحی و پیاده‌سازی هدف‌گیری و مجوزهای tenant-scoped است. در این اصلاح صرفاً لینک ناسازگار با API فعلی حذف شد؛ قابلیت ارسال اطلاعیه ساختمانی اضافه نشده است.
