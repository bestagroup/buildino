# رفع خطای راه‌اندازی بدون دسترسی شل

این راهنما فقط معادل migration موجود `2026_11_02_000001_add_workspace_structure_context` است؛ جایگزین اجرای تمام migrationهای پروژه نیست.

۱. در پنل هاست، phpMyAdmin را باز و دیتابیس همان سایت را انتخاب کنید. نام دیتابیس خطای گزارش‌شده `h426910_panel_buildino` است.
۲. از تب Export یک نسخه پشتیبان بگیرید.
۳. در تب Import، فایل [SQL راه‌اندازی](sql/2026_11_02_onboarding_phpmyadmin.sql) را از کامپیوتر انتخاب و کامل اجرا کنید. این فایل به انتخاب دیتابیس در phpMyAdmin متکی است؛ نام دیتابیس داخل آن ثابت نشده است.
۴. نتیجه آخر باید نام دیتابیس انتخابی، `onboarding_schema = READY` و `migration_records = 1` باشد.
۵. صفحه `/management/building-setup?building_id=5` را بازخوانی کنید. برای این تغییر دیتابیس، نیازی به پاک‌کردن کش یا اجرای دستور شل نیست.

فایل، جدول درخواست اتصال و سه ستون مربوط به نوع مجموعه و تکمیل راه‌اندازی را می‌سازد و نام migration را ثبت می‌کند تا در اجرای بعدی Laravel دوباره اعمال نشود. ستون‌های موجود حفظ می‌شوند و واردکردن مجدد فایل، رکورد migration تکراری ایجاد نمی‌کند. اطلاعات مجتمع‌ها، ساختمان‌ها، واحدها و مالکیت جابه‌جا نمی‌شوند.

اگر Import خطا داد یا نتیجه `INCOMPLETE` بود، همان متن خطای SQL را برای بررسی بفرستید. ثبت دستی یک ردیف در migrations بدون ساخت کامل ساختار، مشکل را حل نمی‌کند. برای اجرای SQL نیازی به ساخت مسیر عمومی وب یا بارگذاری فایل PHP اجرایی روی سایت نیست.
